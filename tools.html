Your work

All your work in one file

Every tool keeps your work only in this browser. Save it as one file to keep a copy, to carry on from another phone or computer, or to hand it to a colleague. Nothing is uploaded.

The file holds the tools' photos too, up to 20 MB of them; restore points stay on this device.

Then clear old entries in these tools to make room: the file keeps them, and opens on any device.

    Works offline too: once a tool has been opened on this device, it and the other tools of its role open without a connection.

    Team sync Off

    Share the tools you choose with your team: every device keeps working without a connection and syncs when it can. The work is encrypted on this device with a key made from the team code, so the server cannot read it.

    Your team code

    On another device, open this box and scan the code or type the six words under “Join a team”. Give it only to your team: whoever has it can read and change the shared work; for someone who should only look, make a read-only code instead. Write it down; it is not shown again.

    Read-only: this device takes the team's work and sends nothing, so it can neither change nor delete the team's copy. Changes made here to the shared tools are not sent, and the next sync replaces them with the team's copy.

    What is sharedWhat this device takes from the team

    No tool has work in this browser yet. What the team shares appears here after the first sync.

    Unticking a tool stops this device sharing it; what the team already has stays. The career tools, your shelf, reading and coaching are personal and never shared. A row deleted on one device is deleted on every device of the team at the next sync, and does not come back.

    Unticking a tool stops this device taking the team's version of it; the work here then stays as it is. The career tools, your shelf, reading and coaching are personal and never shared.

    For someone who should see the team's work but not change it, such as a manager or a screen on the wall. It cannot change or delete anything.

    When someone leaves the team: the work moves to a new code and the old copy is deleted. Every other device then joins again with the new code, and the old read-only codes stop working.

    Read-only code

    On the other device, open this box and scan the code or paste it under “Join a team”. Whoever has it can read the shared work, so give it only to people who may see it. It stops working when the team changes its code.

    The team changed the work of this tool. Reload the page to see it.

    Shared computer

    One browser for the whole desk? Lock the tools with a PIN: your work and the restore points are encrypted on this device, the tools open empty, and the PIN brings everything back. Team sync pauses while locked. Nothing is uploaded.

    Choose a PIN of at least 6 characters. It is kept nowhere: without it the work cannot be read, by anyone.
