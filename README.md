# stiven-catalyst
Modern publication platform for leadership, operations, management insights, field notes and personal projects by Stiven Janaqi.

## How the site works
The site is built with [Eleventy](https://www.11ty.dev/) from the `src/` folder and deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

- `src/content/insights/`, `src/content/notes/`, `src/content/projects/`: one Markdown file per essay, field note and project.
- `src/_data/`: site settings (`site.json`), homepage highlights (`home.json`) and Impressum details (`legal.json`).
- `src/_includes/`: the shared layout (head, header, footer), the article layout and the newsletter block.
- `src/media/`: uploaded images and files.
- `src/tools/` and `src/js/`: the free tools (KPI Diagnostic, 5 Whys, Damage Control, Incomplete Control, Delay Analyzer, Sigma & Control Chart, Shift Handover, Pareto 80/20, Last-Mile CX Control Tower, CV Builder, ATS CV, Cover Letter) and the Six Sigma in the Warehouse course. Their cards come from `src/_data/tools.json`; the diagnostic's statements and advice live in `src/_data/kpiDiagnostic.json`. Damage Control and Incomplete Control share one page partial (`partials/defect-log.njk`) and script (`js/defect-log.js`); everything that differs (wording, fields, stage and cause advice, floor check, example week) lives in `src/_data/damageControl.json` and `src/_data/incompleteControl.json`. Delay Analyzer has its own page and script (`js/delay-analyzer.js`), with reasons, advice, floor check and example week in `src/_data/delayAnalyzer.json`. Sigma & Control Chart (`js/sigma-chart.js`, `src/_data/sigmaChart.json`) holds the sigma and perfect delivery calculators and a p-chart with three signal rules. The course (`tools/six-sigma-dmaic.njk`, `js/dmaic.js`) takes its steps, case, quiz, eight wastes, glossary and charter fields from `src/_data/dmaic.json`. Shift Handover (`js/shift-handover.js`, `src/_data/shiftHandover.json`) has templates for warehouse, hotel front office and delivery station, and carries open issues into the next shift. The warehouse tools share small helpers in `js/tool-kit.js`. CV Builder (`tools/cv-builder.njk`, `partials/cv-builder.njk`, `js/cv-builder.js`) lays a CV out on A4 pages in the browser and prints it as a PDF; its colour themes, CV headings in English, German and Albanian, and the example CVs live in `src/_data/cvBuilder.json`. A company website typed there is the one thing a tool sends out: its logo is loaded from Google's icon service (see Datenschutz). ATS CV (`tools/ats-cv.njk`, `partials/ats-cv.njk`, `js/ats-cv.js`, `src/_data/atsCv.json`) makes a plain one-column CV, matches it to a job ad and saves it as PDF, Word or text; it can start from an old CV, which `js/cv-import.js` reads in the browser from a PDF (with pdf.js, kept in `js/vendor/pdfjs/`), a Word file or pasted text. Cover Letter (`tools/cover-letter.njk`, `partials/cover-letter.njk`, `js/cover-letter.js`, `src/_data/coverLetter.json`) writes the letter in the design of either CV and takes the details from them. Both write Word files with `js/docx-kit.js`. Pareto 80/20 (`tools/pareto.njk`, `partials/pareto.njk`, `js/pareto.js`, `src/_data/pareto.json`) ranks causes from a CSV, an Excel file (.xlsx, unzipped in the browser by `js/cv-import.js`), pasted cells or one of eleven templates for logistics, warehouse and hotel work; it lists every row it leaves out, merges spellings only when asked, and exports PNG, SVG and CSV. Damage Control, Incomplete Control and Delay Analyzer open their logs in it through `sessionStorage` (`sc-pareto-handoff`); its engine is tested in `tests/pareto.test.cjs`. Last-Mile CX Control Tower (`tools/cx-control-tower.njk`, `partials/cx-tower.njk`, `js/cx-tower.js`, `src/_data/cxTower.json`) reads four tables (deliveries, routes, incidents, actions) from CSV files or from the sheets of one Excel workbook, recognising each by its column names, and takes targets from a “Metric | Target” sheet. It computes Perfect Delivery per delivery, the other KPIs with their own denominators, partner and driver scorecards with a minimum sample, a route risk queue, a root-cause Pareto (drawn with the Pareto tool's chart and handed to it through `sessionStorage`), corrective actions and a weekly review; KPIs without an approved target are shown but never scored. Its engine is tested in `tests/cx-tower.test.cjs`. Before the print window, all three CV tools show a short guide to saving the PDF (`js/print-guide.js`). The homepage points to the three career tools (`partials/career-feature.njk`). They run entirely in the browser; logs are kept only in the visitor's `localStorage`.
- `src/books/` (and `de/`, `sq/`): the book *Mall për Durrësin*, read page by page like a real book (`pages/book.njk`, `js/book.js`). The page images, chapters and text come from the PDF through `scripts/book-pages.py`, which writes `src/media/books/mall-per-durresin/` and `src/_data/book.json`. The book also appears on the homepage, the Reflections page and the About page (`partials/book-feature.njk`).
- `.pages.yml`: the editing panel at [app.pagescms.org](https://app.pagescms.org). See `UDHEZUES.md` (in Albanian) for how to add content.

## Run locally
```
npm install
npm start      # http://localhost:8080/
npm run build  # writes the site to _site/
```

## Notes
- Links in templates are written from the site root (`/styles.css`); The site lives at https://stivencatalyst.com/ (`url` in `src/_data/site.json`); Eleventy prefixes links with the path in that address, so moving the site means changing `url` there and everything follows (links, social previews, sitemap, feed).
- Insights and Field Notes have client-side search and topic filters (`src/js/filter.js`); the filter is kept in the URL (`?topic=Operations&q=handoff`) so it can be shared. Essays show a reading time that is counted from the text unless one is typed in.
- The newsletter section stays hidden until `newsletter.action` is set in `src/_data/site.json`.
- The Impressum and Datenschutz pages are only generated once the name and city in `src/_data/legal.json` are filled in.
- `src/fonts/` holds Archivo Black (SIL OFL), used only on devices without Arial Black (Android, Linux).
